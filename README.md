# Full Stack Blog Application

A responsive full-stack blog application that allows users to register, securely log in, create and manage blog posts, and access their own personalized dashboard.

## 🚀 Live Application

Backend API:

https://blog-application-8sc6.onrender.com

## ✨ Features

- User registration and login
- JWT-based authentication
- Password hashing using bcrypt
- Protected routes
- User-specific dashboard
- Create blog posts
- View individual blog posts
- Edit own blog posts
- Delete own blog posts
- Search blogs
- Category filtering
- User profile
- MongoDB database
- RESTful API
- Responsive design for desktop, tablet, and mobile
- Authorization checks for blog editing and deletion

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

### Security

- JSON Web Token (JWT)
- bcryptjs
- CORS
- dotenv
